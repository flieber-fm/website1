Use Flieber in any AI agent

Claude, ChatGPT, Grok, Grok Bot, Claude Code, Codex, Muse or any other agent that supports MCP. The best choice for most people: nothing to install, it works inside the AI apps you already use, and you sign in with your Flieber account.

Let your AI agent guide you

Paste this into a new chat in your agent. Agents that can add MCP servers themselves, such as Claude Code or Codex, connect it after asking you; in Claude, ChatGPT and other chat apps, it walks you through each step.

Prompt
Help me connect Flieber to you as an MCP connector. Server address: https://mcp.flieber.com/mcp. It signs in with OAuth; if an OAuth client ID is needed, use LK4yVcCMOjgiwSsK and leave the client secret blank. If you can add MCP servers yourself, ask me before you change anything, add it and tell me what you did. If you can’t, guide me one step at a time and wait for me after each step: open the settings where connectors or MCP servers are added (in Claude and ChatGPT: Settings, then Connectors), add a custom connector named Flieber with the address above, and if it asks for an OAuth client, choose Use your own OAuth client with the client ID above. Then I sign in with my Flieber account, or create one; on the same page I accept Flieber’s terms and the terms of the AI early access. If my plan or workspace doesn’t allow custom connectors, tell me. When Flieber is connected, show me what Flieber can do.

Or do it yourself

  1. In your AI agent, open the settings where connectors or MCP servers are added and add a custom one (in Claude and ChatGPT: Settings, then Connectors).*
  2. Name it Flieber and paste this address:
    Connector address
    https://mcp.flieber.com/mcp
  3. If it asks for an OAuth client, choose Use your own OAuth client and paste this client ID. Leave the client secret blank.
    OAuth client ID
    LK4yVcCMOjgiwSsK
  4. Sign in with your Flieber account, or create one. On the same page you accept Flieber’s terms and the terms of the AI early access.
  5. Open a new chat and ask: What can Flieber do?

*Subject to the rules of your AI agent’s plan.

Or install it yourself

Install Flieber, then try it. Works with any agent: Claude Desktop, Claude Code, Cursor, Muse, Grok Bot and more.

Before you start

  • A Windows, Mac or Linux computer. No admin rights and no Python needed; the installer sets up everything.
  • An AI tool that can run commands on your computer, such as Claude Desktop, Claude Code, Cursor or Muse.
  • A Flieber account. No account yet? The installer helps you create one.

Step 1: Install Flieber and sign in

This installs Flieber on your computer, signs you in and connects Flieber to your AI tool.

Download the installer, then open the file you downloaded.

Download the installer →

If Windows shows a blue “Windows protected your PC” box, click More info, then Run anyway.

Prefer PowerShell?

Open PowerShell: press the Start key, type PowerShell and press Enter. Paste this command and press Enter.

PowerShell
irm https://cli.flieber.com/install.ps1 | iex

Open Terminal: press Cmd + Space, type Terminal and press Enter. Paste this command and press Enter.

Terminal
curl -fsSL https://cli.flieber.com/install.sh | sh

Open a terminal window, paste this command and press Enter.

Terminal
curl -fsSL https://cli.flieber.com/install.sh | sh

Your browser opens the Flieber sign-in page. Sign in, or create your account: on the same page you accept Flieber’s terms and the terms of the AI early access. Back in the window, you’ll see your Flieber organizations. No organization yet? The installer offers to create one with you.

✓ You’ll see your Flieber organization listed. Flieber is now connected to your AI tool.

Using Claude Desktop? Quit it completely and open it again.

Run the same installer again any time to update Flieber. Review the installer before running it

Open a new chat in your AI tool and paste a prompt.

  • Show me the forecast for my top 10 products for the next 90 days.
  • Which of my SKUs are not mapped to a product yet?
  • Help me connect my Shopify store to Flieber.

Safety

Built to be safe

Your agent shows you every change first and waits for your OK before applying it.

Going live is permanent, so your agent always asks you to confirm it.

You sign in on Flieber’s own page. You never paste a password or key into a chat.

Your agent sees only what your Flieber account is allowed to see.

Actual sales, adjusted sales and forecasts are kept separate, so numbers are never mixed.

Questions

Questions

Which AI tools work with Flieber?

Any agent that supports MCP, such as Claude, ChatGPT, Grok, Grok Bot, Claude Code, Codex and Muse, through the connector. Agents that run commands on your computer, such as Claude Code, Cursor, Codex and Muse, can also use Flieber CLI.

Should I add the connector or install the CLI?

Both give your agent the same Flieber data and actions. Add the connector if you use Flieber from an AI app such as Claude, ChatGPT or Grok: there is nothing to install. Install the CLI if you build with AI on your own computer and want Flieber as a command your agent, scripts and scheduled jobs can run, or need to sign in with an API key or on a remote machine.

Do I need to be technical?

No. Paste one prompt into your AI tool and it sets Flieber up for you, or install it yourself with the steps on this page.

Do I need a Flieber account?

Yes. The installer walks you through creating one. Your free trial starts when you create your account in Flieber.

Can my agent change things in Flieber?

Only with your OK. Your agent shows you every change first and waits for your approval.

Is my data used to train AI models?

No. Flieber does not train on customer data, and its AI providers are set up not to.

Is this an MCP server?

Yes. Flieber connects through MCP, the open standard that lets AI tools use other software. The developer reference has the details.

Does it work without an AI tool?

Yes. Everything here also works in the Flieber app and in Slack.
