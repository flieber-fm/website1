Install it yourself

Before you start

  • A Windows, Mac or Linux computer. No admin rights and no Python needed; the installer sets up everything.
  • Claude Desktop, Claude Code, Cursor or Muse installed.
  • A Flieber account. No account yet? The installer helps you create one.

Early access Two steps, in order, then try it. About 5 minutes.

Step 1: Install Flieber and sign in

This installs the Flieber app for your computer and signs you in.

Download the installer, then open the file you downloaded.

Download the installer →

If Windows shows a blue “Windows protected your PC” box, click More info, then Run anyway.

Prefer PowerShell?

Open PowerShell: press the Start key, type PowerShell and press Enter. Paste this command and press Enter.

PowerShell
irm https://cli.flieber.com/install.ps1 | iex

Open Terminal: press Cmd + Space, type Terminal and press Enter. Paste this command and press Enter.

Terminal
curl -fsSL https://cli.flieber.com/install.sh | sh

Open a terminal window, paste this command and press Enter.

Terminal
curl -fsSL https://cli.flieber.com/install.sh | sh

Your browser opens the Flieber sign-in page. Sign in. Back in the window, you’ll see your Flieber organizations. No organization yet? The installer offers to create one with you.

✓ You’ll see your Flieber organization listed.

Run the same installer again any time to update Flieber. Review the installer before running it

Step 2: Connect Flieber to your AI tool

This adds the Flieber connection to your AI tool. What's this?

After Step 1, in the same window, paste this command and press Enter. Then quit Claude Desktop completely and open it again.

Claude Desktop
flieber mcp register --client claude-desktop

On Windows, use PowerShell for this, not another terminal.

After Step 1, in the same window, paste this command and press Enter. This adds Flieber to all your projects.

Claude Code
flieber mcp register --client claude-code

The installer also teaches Claude Code how to use Flieber well.

After Step 1, in the same window, paste this command and press Enter.

Cursor
flieber mcp register --client cursor

For technical teams

Point your tool at this command to run the Flieber connection on your computer.

Local connection
uvx flieber@latest mcp

To let your tool make changes, always after your approval, set FLIEBER_OAUTH_WRITES=1.

If your tool can’t find uvx, use its full path: run which uvx on Mac and Linux, or where uvx on Windows.

Safety

Built to be safe

Claude shows you every change first and waits for your OK before applying it.

Going live is permanent, so Claude always asks you to confirm it.

Your sign-in is saved on your computer. You never paste a password or key into a chat.

Claude sees only what your Flieber account is allowed to see.

Actual sales, adjusted sales and forecasts are kept separate, so numbers are never mixed.

Questions

Questions

Which AI tools work with Flieber?

Claude Desktop, Claude Code, Cursor and Muse today. Claude in the browser is coming soon. Flieber AI customers can also use Flieber Studio in Claude, ChatGPT and Cursor.

Do I need to be technical?

No. Paste one prompt into your AI tool and it sets Flieber up for you, or follow the three steps on this page.

Do I need a Flieber account?

Yes. Creating your Flieber account is the first step. The installer walks you through it.

Can Claude change things in Flieber?

Only with your OK. Claude shows you every change first and waits for your approval.

What’s the difference between installing Flieber and Flieber Studio?

Installing Flieber gives your AI tool Flieber’s data and actions directly. Flieber Studio is Flieber’s analyst agent: your AI tool asks it a question and it answers, typically in 30 seconds to 5 minutes.

Is my data used to train AI models?

No. Flieber does not train on customer data, and its AI providers are set up not to.

Is this an MCP server?

Yes. Flieber connects through MCP, the open standard that lets AI tools use other software. The developer reference has the details.

Does it work without an AI tool?

Yes. Everything here also works in the Flieber app and in Slack.
